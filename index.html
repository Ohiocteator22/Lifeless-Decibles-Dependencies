What Decibles is for

Built for beginners learning to ship their first app and for experienced developers tired of hand-wiring the same toolchain every project. Decibles doesn't replace your compilers and SDKs — it orchestrates the ones that already exist.

Three targets to start

Desktop applications, web applications, and backend services and APIs. Python with PySide6 for desktop, FastAPI for backend — proposed directions, not locked commitments.

Your project stays yours

Ordinary source files, conventional structure, a Decibles manifest only where it helps. Existing projects import without being converted into a proprietary format.

Lightweight by default

The core install stays small. Language support, SDKs, and optional components download on demand, with verification and clear progress at every step.

Honest about platforms

Cross-platform support is based on real toolchains and real capabilities per OS — not a simulated "works everywhere" that quietly doesn't.

FAQ

Is Decibles available yet?

No. It's in the planning phase — no implementation has started. This site will be updated as that changes.

Will it force me into a proprietary project format?

No. Decibles is designed to preserve conventional project structures and existing ecosystem configuration, adding a manifest only where it genuinely helps.

What languages and frameworks will it support?

It will support multiple languages, but prioritize complete, well-tested workflows for a smaller set — starting with Python/PySide6 for desktop and FastAPI for backend.

Does it reinvent compilers and build tools?

No. Decibles orchestrates established compilers, SDKs, package managers, debuggers, and build systems rather than replacing them.
